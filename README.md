# 🌍 World Climate Change Temperature Analysis Dashboard

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze global climate change and temperature trends. The project transforms climate data into meaningful visual insights through interactive charts, KPIs, and filters.

## 🎯 Objectives

- Analyze global temperature trends
- Identify changes in temperature over time
- Compare climate patterns across regions
- Visualize climate-related data interactively
- Generate meaningful insights from historical data

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📈 Dashboard Features

- Interactive charts and graphs
- KPI indicators
- Temperature trend analysis
- Country/region comparisons
- Interactive filters and slicers
- Time-based analysis
- Data-driven insights
